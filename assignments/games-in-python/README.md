
# 📘 Assignment: Jogo da Forca

## 🎯 Objective

Construir o clássico jogo de adivinhar palavras usando strings, loops, condicionais, seleção aleatória e entrada de dados do usuário em Python.

## 📝 Tasks

### 🛠️ Seleção de Palavra e Exibição do Progresso

#### Descrição
Crie um jogo da Forca em que a palavra oculta seja escolhida aleatoriamente de uma lista predefinida e o progresso seja mostrado a cada rodada.

#### Requisitos
O programa concluído deve:

- Selecionar palavras aleatoriamente de uma lista predefinida
- Mostrar o progresso atual da palavra no formato `_ _ _`, revelando as letras já adivinhadas


### 🛠️ Palpites e Controle de Tentativas

#### Descrição
Aceite palpites de letras do jogador e acompanhe quantas tentativas incorretas ainda restam.

#### Requisitos
O programa concluído deve:

- Aceitar palpites de letras do usuário
- Rastrear o número de tentativas incorretas restantes


### 🛠️ Condições de Vitória e Derrota

#### Descrição
Encerre o jogo quando a palavra for adivinhada ou quando as tentativas se esgotarem, exibindo a mensagem correspondente.

#### Requisitos
O programa concluído deve:

- Encerrar quando a palavra for adivinhada ou as tentativas se esgotarem
- Exibir mensagens de vitória ou derrota
